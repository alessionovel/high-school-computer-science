## Projects

- [`bike-sharing`](projects/bike-sharing): PHP/MySQL bike-sharing platform. Users register, request a smart card, top up their balance, find stations on a map and see their rentals; the back office manages card requests, users with a negative balance and reports. `docs/` holds the analysis document, the ER model and the network topology (designed for the Networking course).
- [`coding-week-game-search`](projects/coding-week-game-search): Vue.js + Axios page that searches video games through the [RAWG API](https://rawg.io/apidocs). Put your API key in `apikey.js`.
