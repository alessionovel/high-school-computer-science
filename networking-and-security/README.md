# Networking and Security (Sistemi e Reti)

| Folder | Content |
| --- | --- |
| [`cryptography-java/`](cryptography-java) | Java implementations: Caesar cipher (with dictionary-based brute force), monoalphabetic cipher (frequency analysis), symmetric (DES) and asymmetric (RSA) encryption with the Java Cryptography API |
| [`openssl/`](openssl) | OpenSSL labs: exchanging signed and encrypted messages with classmates, file encryption, hashing and digital signatures, self-signed certificate |
| [`packet-tracer/`](packet-tracer) | Cisco Packet Tracer networks: VLANs, router-on-a-stick, multilayer switch, static routing, RIP, NAT and port forwarding, SSH, cloud |
| [`theory/`](theory) | Notes and assignments: digital signature analysis, hybrid encryption diagram, firewall design, network applications, a review of the film *WarGames* |

Private keys generated during the labs have been removed; the public material (messages, hashes, certificate) is kept.
