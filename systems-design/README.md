# Systems Design (TPSIT)

*Tecnologie e Progettazione di Sistemi Informatici e di Telecomunicazioni*

## Java concurrency

| # | Project | Topic |
| --- | --- | --- |
| 01 | `multithreading-basics` | Threads vs. sequential execution |
| 02 | `shared-counter` | Several threads updating a shared counter |
| 03 | `horse-race` | Threads racing on a shared resource |
| 04 | `nightclub` | Bouncer and queue of customers |
| 05 | `supermarket-checkouts` | Customers served by several checkouts |
| 06 | `parking-lot` | Limited parking spaces and waiting cars |
| 07 | `producer-consumer-1`, `producer-consumer-2` | Producer/consumer with a shared buffer (two variants) |
| 08 | `gas-station` | Pumps, tank refill and customers |
| 09 | `client-server` | TCP sockets |

Each project is an Eclipse project: the code is in `src/`.
